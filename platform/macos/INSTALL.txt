Rail for macOS is ad hoc signed and has not been notarized by Apple.

1. Download the DMG from the Rail GitHub release. Compare its SHA-256 hash
   with SHA256SUMS-macos on the same release page.
2. Open the DMG, drag Rail to Applications, then try to open Rail.
3. If macOS blocks it, open System Settings > Privacy & Security and choose
   Open Anyway for Rail. Confirm with your Mac login password.

Only open a copy you trust. The checksum detects download corruption, but a
checksum published alongside the file is not proof of the developer's identity.
